# Enterprise Administration Guide

## Overview

The Administration platform provides enterprise-grade management for organizations, users, roles, audit, secrets, API keys, and system settings.

## Modules

### User Management
- CRUD operations for all platform users
- Invite, suspend, reactivate, and delete users
- Role assignment and session management
- User activity timeline and login history

### Organization Management
- Organization hierarchy (departments, teams, business units)
- Organization settings and policies
- Subscription and feature management
- Domain verification

### Role-Based Access Control (RBAC)
- Role definitions with permission groups
- Role templates for workspaces and organizations
- Inherited and effective permissions
- Permission audit trail

### System Settings
- General, branding, authentication, security
- Runtime, knowledge, agents, workflows, missions
- Storage, database, Redis, vector store
- Email, AI providers, logging, monitoring
- Feature flags

### Audit Center
- Every action recorded with actor, resource, operation
- Filters, search, export, timeline
- Organization, workspace, user scoping

### Deployment Center
- Deployment history and status
- Rollback, version history, health
- Logs, artifacts, release notes

### License Management
- License CRUD, subscription, seat usage
- Limits, quota, expiration tracking
- Enterprise edition feature flags
